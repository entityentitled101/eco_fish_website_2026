# 绿佳元 - 清水生态养殖官网

专业的生态养殖企业网站，展示清水生态养殖技术与产品。

## 技术栈

- **框架**: React 19 + TypeScript + Vite
- **样式**: Tailwind CSS (CDN)
- **字体**: Noto Serif SC + Noto Sans SC
- **图标**: Lucide React

## Git 使用指南

### 📦 第一次初始化 Git 仓库（只需执行一次）

如果你是第一次使用 Git，按照以下步骤操作：

```bash
# 1. 初始化 Git 仓库
git init

# 2. 添加所有文件到暂存区
git add .

# 3. 提交更改（第一次提交）
git commit -m "Initial commit: 绿佳元网站初始版本"

# 4. 添加远程仓库地址（替换为你的 GitHub 仓库地址）
git remote add origin https://github.com/你的用户名/你的仓库名.git

# 5. 推送到 GitHub（首次推送）
git push -u origin main
```

**注意**：第4步中的 `https://github.com/你的用户名/你的仓库名.git` 需要替换为你在 GitHub 上创建的仓库地址。

例如：
```bash
git remote add origin https://github.com/zhangsan/lvjiayuan-website.git
```

---

### 🔄 后续每次更新代码（常用命令）

每次修改代码后，使用以下命令提交更改：

```bash
# 1. 查看修改了哪些文件
git status

# 2. 添加所有修改的文件到暂存区
git add .

# 3. 提交更改（附带说明信息）
git commit -m "描述本次修改的内容"

# 4. 推送到 GitHub
git push
```

**常用提交信息示例**：
```bash
git commit -m "更新产品页面布局"
git commit -m "修复首页按钮样式"
git commit -m "添加联系我们弹窗功能"
```

---

### 🔧 常用 Git 命令速查

| 命令 | 说明 |
|------|------|
| `git status` | 查看当前文件状态 |
| `git add .` | 添加所有修改到暂存区 |
| `git add 文件名` | 添加指定文件到暂存区 |
| `git commit -m "说明"` | 提交更改 |

| `git pull` | 从远程仓库拉取最新代码 |

## 本地运行

**前置要求**: Node.js

1. 安装依赖：
   ```bash
   npm install
   ```

2. 启动开发服务器：
   ```bash
   npm run dev
   ```

3. 在浏览器中打开 `http://localhost:5173`

## 项目结构

- `components/` - React 组件
- `constants.ts` - 数据常量配置
- `types.ts` - TypeScript 类型定义
- `index.html` - HTML 入口文件
- `/logo（长）.png` - 企业 logo
- `/fish（1）.jpg` - 首页背景图
- `/contrast (1).jpg` - 传统养殖模式图
- `/contrast (2).jpg` - 清水生态养殖模式图
- `utils.ts` - 工具函数（如图片路径处理）

## 阿里云 OSS 静态构建

在项目根目录运行 `npm run build:oss`，使用 `dist/` 中的构建产物部署到 OSS 静态网站根目录。这个构建的资源路径以 `/` 为基准。GitHub Pages 继续运行 `npm run build`。
